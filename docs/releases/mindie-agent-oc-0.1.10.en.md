# mindie-agent-oc 0.1.10: Default-Enabled `knowledge_*` Tools, Pure-Node Silent Skill Injection, and Consent-First `session.idle` Capture

[中文](mindie-agent-oc-0.1.10.md)

- **Default-Enabled `knowledge_*` on `mindie-tools` MCP & Zero-Gate `knowledge_cli.py`**: Exposes `knowledge_query`, `knowledge_explain` (both marked `readOnlyHint=True` and dispatched on `read_pool`), `knowledge_feedback`, `knowledge_distill`, and `knowledge_sync` directly on `mindie-tools` on startup alongside direct `knowledge_cli.py` execution, falling back cleanly to `_CONNECTION_SESSION_ID` / `"oc-cli-default"` and auto-provisioning a default session lease (`not_before=0.0`) on demand with full Principle 14 Receipt Honesty.
- **Silent `opencode_host.mjs` & Zero-Subprocess `SKILL.md` Context Injection**: Removes `ctx.command.transform` and `ctx.session.hook("prompt")` user command hooks completely; `ctx.session.hook("context")` injects `<mindie-agent-skill>` directly from `SKILL.md` cached in memory in pure Node.js (stripping YAML frontmatter with zero Python subprocess spawns per prompt) while lazily starting `ensureSummaryServer()`. Removes `disable-model-invocation: true` from `SKILL.md` (21 lines) and purges all user-facing command mentions across manifests and docs.
- **Pure-Node Consent-First `session.idle` Capture**: Checks community sharing consent (`mindie-community.json` + `mindie-consent.json`) and authorized `project_roots` in pure Node.js before spawning `capture_stop.py` (and before opening SQLite in `capture_stop.py`); spawns zero subprocesses (`0ms` cold path) and creates zero `admission.sqlite3` files when sharing is off or out of scope, while auto-provisioning the session lease (`not_before=0.0`) and capturing redacted public turns when authorized.
