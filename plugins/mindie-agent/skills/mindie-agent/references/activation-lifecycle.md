# Session Isolation & Consent-Gated Capture

- **Default-On Tools**: `remote_*`, component, diagnostic, `mindie_doctor`, and `knowledge_*` tools are available on startup with no manual activation; harness routing falls back to a connection session and provisions a default lease (`not_before=0.0`) on demand.
- **Session Context Isolation**: `session.hook("context")` injects cached `SKILL.md` guidance directly in pure Node.js for top-level sessions (`!parentID && !forkSessionID`), and `shell.hook("create.before")` binds `OPENCODE_SESSION_ID` strictly to commands initiated by that session. Subagents and forked sessions never inherit top-level context.
- **Consent-First Capture**: on terminal session events, `opencode_host.mjs` checks `mindie-community.json` (`enabled === true`), `mindie-consent.json` (`choice` is `contribute` or `local-only`), and canonical `project_roots` in pure Node before spawning `mindie_launch.py hook stop`. When sharing is off or out of scope, zero subprocesses are spawned and zero SQLite files are created.
- **Sharing Tiers**: `setup.py sharing --enable` selects contribute, `--local-only` captures without reporting, and `--disable` stops capture; `--status` is read-only.
- **Authorized Capture**: `mindie_launch.py` re-verifies consent, preserves explicit admission revocation, computes `auth_boundary = max(enabled_at, activated_at)`, projects redacted public text read-only (`?mode=ro`) into `state/oc/transcripts/<sessionID>.jsonl`, and hands the turn receipt to `capture_hook` with the deterministic `eventID` as `turn_id`.
